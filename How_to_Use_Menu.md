How to use the menu

1. Download the "NetflixDataMenu.py" file. This is where the code for the menu is stored.

2. Download each of the .csv tables so you can access the data while using the table. 

3. Download the dataload file and run it in your terminal, entering in your username, password, and DSN in the code. 

3. Edit the code to add your username and password, along with your DSN to your oracle database.

4. Run the code in your terminal which will bring up the menu from there. Now you can use the table as needed.
